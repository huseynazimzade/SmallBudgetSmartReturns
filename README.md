# SmallBudgetSmartReturns
Kiçik büdcəli investorlar üçün inflyasiyadan təmizlənmiş (Real Price) portfel analizi. CPI göstəriciləri ilə 8 aktivin (Səhm, Valyuta, Metal) CAGR, Volatillik, Sharpe Ratio, Max Drawdown, VaR və Skewness/Kurtosis risk təhlili. Python, Power BI və Streamlit ilə interaktiv vizuallaşdırma və simulyasiya.
